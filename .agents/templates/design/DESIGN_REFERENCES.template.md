## 1. Curated Reference Pieces

### Reference 1: The Oxford University Gazette (Editorial Typography)
- **Source / URL**: Academic editorial archive
- **Key Craft Elements**: Disciplined 2-column typographic layout, bold black headlines with restrained green section rules, zero decorative filler.
- **What to Adapt for EduCore**: Four-tier hierarchy and high-contrast headlines with clean hairline dividers.
- **What to Avoid**: Overly dense text columns without responsive mobile reflow.

### Reference 2: Stripe Invoicing & Dashboard (Functional Density)
- **Source / URL**: Stripe Docs / Billing interface
- **Key Craft Elements**: Crisp 1px borders (`border-slate-200`), clear visual status badges (green/amber/rose), clear monospaced tabular figures.
- **What to Adapt for EduCore**: Clean table card wrappers, status pills with subtle backgrounds, and high-visibility keyboard focus rings.
- **What to Avoid**: Monochromatic dark theme that reduces accessibility for school administration staff.

### Reference 3: Swiss Style / International Typographic Movement
- **Key Craft Elements**: Asymmetric grid alignment, generous whitespace, mathematical hierarchy, clear visual anchor points.
- **What to Adapt for EduCore**: 60/40 asymmetric layout splits and anchor credential badges.
