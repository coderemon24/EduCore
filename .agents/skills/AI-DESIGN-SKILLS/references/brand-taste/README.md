# Brand and Taste References

Use this folder for references that communicate the overall visual world, personality, taste, art direction, typography philosophy, color behavior, imagery, or composition you respond to.

References may come from completely different industries, including branding, editorial, architecture, fashion, packaging, websites, typography, and photography.

This folder means:

> I like how this feels.

It does not mean:

> Copy this design.

Use descriptive filenames or add notes about what matters when the reason is not obvious.
