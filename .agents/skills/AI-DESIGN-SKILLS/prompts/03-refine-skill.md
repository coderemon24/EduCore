# Refine Design Skill

Help me improve an existing design skill based on real generated work.

Do not immediately rewrite the skill.

First diagnose the problem.

Use:

- the current `SKILL.md`
- the design brief
- the generated result
- my feedback
- any additional evaluation I provide

Determine whether the problem came from:

- missing guidance
- vague guidance
- overly rigid guidance
- conflicting rules
- incorrect interpretation
- medium-specific guidance being absent
- an instruction being ignored
- a problem in the brief
- a rule encouraging repetitive design

For every meaningful issue, show:

## Problem

What went wrong?

## Likely Cause

Why did the skill contribute to the problem?

## Proposed Change

What is the smallest useful change to the skill?

## Why It Generalizes

Why should this improve future work rather than only fixing this one example?

Do not add a new rule for every isolated mistake.

Do not overfit the skill to one output.

Do not make the skill longer unless the additional guidance is genuinely useful.

Prefer improving or clarifying an existing rule over adding another rule.

Also check whether any existing rule can be removed or simplified.

Ask me to approve the proposed changes.

Only after approval, update the complete `SKILL.md`.

Preserve the existing skill name and purpose unless I explicitly ask to change them.

The goal is to make the skill clearer and more useful, not more complicated.
