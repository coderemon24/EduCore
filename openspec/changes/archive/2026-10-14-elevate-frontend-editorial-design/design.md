# Design

## Context

The KitoMark public application is built with Laravel 12 Blade views, Tailwind CSS v4, Alpine.js, and GSAP. The current frontend employs design tropes commonly generated by AI assistants:
- Multiple 800px blurred glow orbs (`.ambient-glow`) layered behind content.
- Full-viewport fixed grid lines (`.bg-grid`).
- A Three.js particle cloud (`three-hero.js`) running in an absolute canvas behind hero typography.
- A preloader script (`preloader.blade.php`) that intercepts all link clicks with `e.preventDefault()` and artificial `setTimeout` delays.
- Tracked-out uppercase monospace eyebrows (`01 // ZERO SLOP PRINCIPLE`, `FEATURE // WELCOME`), blinking green/orange radar dots (`.blink-dot`), and 2px hover laser lines (`.team-laser-line`).

This design plan transitions the frontend into a bespoke, high-contrast editorial studio aesthetic while preserving 100% compatibility with Laravel backend controllers and data models.

## Goals / Non-Goals

**Goals:**
- Eliminate AI slop aesthetics (glow halos, grid patterns, blinking radar dots, laser hover lines, 3-stop gradient text).
- Implement an authentic, high-contrast editorial typography and layout hierarchy.
- Replace the arbitrary Three.js particle background with an interactive, responsive Agency Deliverables Showcase component.
- Eliminate navigation delay and link interception in `preloader.blade.php` for instant page loads.
- Maintain seamless dark mode (`html.dark`) and light mode (`html.light`) compatibility with disciplined `#FF5A00` brand accenting.

**Non-Goals:**
- Modifying backend Eloquent models, migrations, or database tables.
- Modifying the `/admin` CMS dashboard layout or controllers.
- Removing or altering existing client-side functionality (such as Alpine.js consultation modal submission or dark/light mode persistence).

## Decisions

### Decision 1: Design Tokens & CSS Architecture (`input.css`)
- **Rationale**: Purge decorative glow utilities (`.ambient-glow`, `.bg-grid`, `.team-laser-line`, `.team-glow-bg`, `shadow-brand-glow`, `.gradient-text`) and replace them with crisp, architectural utility classes.
- **Tokens**:
  - Dark background: deep obsidian `#090B0E`, card surface `#0F131C`, hover surface `#151B27`.
  - Light background: crisp gallery white `#FFFFFF`, surface `#F8FAFC`, hover surface `#F1F5F9`.
  - Hairline borders: `border: 1px solid var(--border-subtle)` (`rgba(255, 255, 255, 0.08)` in dark; `#E2E8F0` in light).
  - Brand Orange: `#FF5A00` applied selectively to primary action buttons, active navigation markers, and key numerical figures.
  - Border Radii: Standardized to `rounded-xl` (12px) and `rounded-lg` (8px), eliminating inconsistent nested 32px pill cards.

### Decision 2: Interactive Agency Deliverables Hero Showcase
- **Rationale**: The Three.js particle canvas consumes client resources without illustrating what KitoMark actually builds. Replacing it with an interactive deliverables showcase immediately demonstrates agency capability and proof of work.
- **Component Design**:
  - Uses Alpine.js (`x-data="{ activeDeliverable: 'marketing' }"`) embedded directly in the hero of `index.blade.php`.
  - Three interactive tabs:
    1. **High-Intent Growth & Paid Media**: Funnel metrics, conversion attribution model, ROAS visualization.
    2. **Bespoke Web Architecture**: Core Web Vitals 100/100 score, responsive component topology, sub-second latency audit.
    3. **Enterprise App Engineering**: Cloud synchronization, cross-platform architecture, secure API telemetry.
  - Responsive: Renders as interactive horizontal tabs on desktop and stacked cards on mobile viewports.

### Decision 3: Zero-Latency Navigation Cleanup (`preloader.blade.php`)
- **Rationale**: Intercepting link clicks and delaying page transitions degrades perceived performance and violates web usability best practices.
- **Architecture**:
  - Remove `click` event listeners that call `e.preventDefault()` on `<a>` tags.
  - Remove artificial timeout interceptors on `Alpine.store('app').openConsultation`.
  - Retain only a lightweight initial window load fade-out (or cleanly remove the preloader overlay entirely), allowing standard browser page loads to occur instantly.

### Decision 4: Editorial Layout & Component Refactoring
- **Homepage (`index.blade.php`)**:
  - Hero headline: High-contrast solid typography with tight tracking (`tracking-tight leading-[1.08]`), replacing `.gradient-text` and `.highlight-orange` with crisp font weights and direct brand color accents.
  - Client Logos Scroller: Clean, single-track infinite scroll without redundant markup clones.
  - Core Services, Case Studies, and ROI Calculator: Solid hairline borders, removed blinking dots, clean executive typography.
- **About Page (`about.blade.php`)**:
  - Replace `01 //` monospace badges with clean numbered editorial paragraphs.
  - Remove `.team-laser-line` and `.team-glow-bg` from leadership cards in favor of crisp border and subtle elevation hover transitions.
- **Details Views (`services/details.blade.php`, `case-studies/details.blade.php`)**:
  - Streamline telemetry headers, removing fake radar tags and focusing on structured technical specifications.

## Risks / Trade-offs

- **Risk: Build Step / Tailwind Output**: Modifying `input.css` requires recompiling `output.css` via Tailwind CLI (`npm run build:css` or `npm run build`).
  - *Mitigation*: Run asset compilation commands via Docker/Node to ensure compiled output is in sync.
- **Risk: Light Mode Contrast**: Removing universal glows and gradient text could expose unstyled contrast bugs in light mode.
  - *Mitigation*: Ensure explicit CSS variables `--text-primary` and `--border-subtle` are tested in both `html.dark` and `html.light` states.
